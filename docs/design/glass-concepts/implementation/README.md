# 暖玉绿第一阶段实现

> 历史阶段记录：此处截图仅展示最初的通知页与导航实现。最新页面已进一步精修，请看 [当前设计规范](../../DESIGN_SYSTEM.md) 和 [最新验收配图](../../acceptance/ACCEPTANCE.md)。

2026-10-29，用户选择 B，并同意先实现通知页与底部导航。

## 本轮范围

- 共用暖玉绿浅色与深色主题，不再跟随系统壁纸动态取色；其他页面继承配色，尚未重做布局。
- 静态柔光背景、半透明 Surface、渐变细边框。属于轻量磨砂效果，不是实时背景模糊，不需要额外图形依赖。
- 底部五入口使用独立圆角导航容器，预留系统导航栏和内容安全区。
- 通知页简化正常采集状态，保留未授权、未连接和暂停状态；搜索支持一键清除。
- 测试通知、日志、清空进入更多菜单；原通知权限请求和清空确认保持不变。
- 通知卡片突出应用、标题、时间与正文，使用应用名称首字作为标识；标签支持换行。
- 未改动数据库、采集服务、规则引擎和转发逻辑。

- `:app:testDebugUnitTest`：45 项通过，0 失败。
