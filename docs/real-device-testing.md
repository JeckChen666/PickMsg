# 真机测试清单

模拟器只能验证逻辑正确性。通知采集类工具的真正考验在真机 ROM 上，按以下清单逐项过一遍。

## 0. 安装前

- [ ] 使用 release 签名包（与本机已装版本签名一致，否则更新安装会丢数据）
- [ ] 记录 keystore 与密码的备份位置（丢失 = 无法覆盖安装）

## 1. 授权与基础采集

- [ ] 通知使用权授权流程可走通（应用内「前往系统设置授权」按钮）
- [ ] 各系统应用（短信/邮件/应用商店）通知均被采集，标题/内容完整
- [ ] 微信/QQ 等自定义布局通知的文本提取效果（无内容时记录里应可见"无文本跳过"日志而非空白记录）
- [ ] 锁屏状态下收到通知，解锁后检查记录与提取内容
- [ ] 验证码类通知：确认系统脱敏时应用正确打上「敏感占位」标签且不做转发

## 2. ROM 保活（国产 ROM 重点）

- [ ] 电池优化豁免（应用内引导按钮）已授予
- [ ] ROM 自带「自启动管理」中允许 PickMsg 自启
- [ ] ROM 通知使用权在重启后仍有效（部分 ROM 重启后会回收）
- [ ] 锁屏充电 1 夜后：服务是否自动重连（我的页状态卡可见）
- [ ] 从最近任务划掉应用后：监听是否自动恢复（部分 ROM 划掉即杀且不重绑，此时需前台服务开关）
- [ ] 开启「前台服务常驻」后重复以上两项（这就是前台服务的意义）

## 3. 前台服务与磁贴

- [ ] 前台服务通知带「暂停采集」按钮，点击生效（状态卡变暂停）
- [ ] 快捷设置磁贴「采集开关」可添加、可切换、图标状态正确
- [ ] 省电模式 / 超级省电下采集是否存活

## 4. 场景与计划任务

- [ ] Wi-Fi 场景：连上家庭路由（SSID 命中）与断开时规则行为差异
- [ ] 门户 Wi-Fi（公司/咖啡店）下网络场景判定是否合理
- [ ] 计划任务在锁屏免打扰状态下是否准时触发（无精确闹钟权限时会延迟属正常，设置页有提示）
- [ ] 重启手机后计划任务自动恢复

## 5. 规则与动作

- [ ] 真实验证码短信/通知：复制动作进剪贴板可用性
- [ ] Webhook 打到真实机器人（企微/飞书/钉钉任一）
- [ ] 邮件转发用真实 SMTP 授权码发一封
- [ ] 手环/手表佩戴场景：重复提醒次数与清理延迟体感
- [ ] 「打开原通知目标」在隐私敏感应用（银行类）上的行为是否符合预期——它等于代替用户点击

## 6. 数据与备份

- [ ] WebDAV 备份到真实网盘（坚果云等支持 WebDAV 的服务）
- [ ] 清空数据 → 从 WebDAV/本地文件恢复，验证规则/场景/计划完整
- [ ] CSV 导出用 Excel/Numbers 打开中文不乱码（UTF-8）

## 已知平台边界（不是 Bug）

- Android 15 起含验证码内容对监听器自动脱敏（除非系统授予 RECEIVE_SENSITIVE_NOTIFICATIONS，普通应用拿不到）
- 应用更新自身通知（同一 key 重新 post）时 postTime 变化，会被视为新记录
- 部分 ROM「划掉最近任务」即冻结应用，必须开前台服务常驻
