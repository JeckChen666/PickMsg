# v0.4.0 · 暖玉绿界面与交互精修

## 界面更新

- 引入暖玉绿浅色和深色主题，统一圆角、间距、文字层级和基础组件。
- 通知页使用柔光背景与半透明卡片，测试通知、日志和清空收进更多菜单。
- 规则、场景和计划采用整卡编辑，开关独立操作，改善长名称显示。
- 编辑、详情和工具页隐藏主导航，支持页内系统返回与键盘避让。
- 详情正文独立展示，诊断信息默认折叠；备份及邮件配置按需展开。
- 改善窄屏、大字体、横向尺寸及弹窗滚动表现；删除操作增加二次确认。

## 修复与维护

- 修复应用交错分组可能产生重复列表键的问题，并补充 5 项回归测试。
- 修复置顶后的详情按钮状态、深色局部文字颜色与半透明导航投影表现。
- 整理使用说明、开发文档、设计规范、当前截图与验收记录。

## 验证与边界

- 50 项单元测试通过；发布前重新构建 Debug 和正式签名 Release APK。
- Android 15 专用模拟器已检查主要界面流程，以及部分窄屏、2 倍字体、横向尺寸和深色状态。
- 完整 Lint 仍有 10 个既有错误，集中在桌面小组件、快捷磁贴和清单；不把构建通过等同于完整静态检查通过。
- API 26 真机、厂商 ROM、真实转发/备份与完整无障碍流程仍需验证。未新增未保存草稿的自动恢复能力。

## 安装与升级

- 最低支持 Android 8.0（API 26）；`versionCode = 4`。
- 下载 `PickMsg-v0.4.0-release.apk`，使用与上一版相同的正式签名。
- 先尝试覆盖安装，勿为绕过签名冲突直接卸载旧版。JSON 备份只含规则、场景与计划，不含通知历史。
- 同时提供 SHA-256 校验文件。

详细验证范围见 [界面精修验收报告](../design/acceptance/ACCEPTANCE.md)。
