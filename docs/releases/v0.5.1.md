# v0.5.1 · 米白底品牌图标

基于 v0.5.0 的图标小版本，保留常驻通知更新折叠等已有功能。

发布入口：[v0.5.1](https://github.com/JeckChen666/PickMsg/releases/tag/v0.5.1)。

## 更新内容

- 使用选定的 A4-3 口袋造型与米白底板，避免绿色标志与绿色外底混在一起。
- 接入 Android 自适应、圆形及多密度回退图标，补充 Android 13 单色主题图标资源。
- 通知栏、重发通知、计划通知和快捷设置磁贴统一使用专门的单色标志。
- 增加可重现的离线图标生成脚本、商店尺寸导出和裁切预览。
- 版本更新为 `0.5.1`，`versionCode = 6`；不修改采集、折叠、规则或转发逻辑。

## 资源与验证

图标来源、资源分工及重新生成方式见 [品牌资源说明](../../assets/branding/README.md)。

Debug / Release 本地构建成功，53 项现有单元测试通过；正式 APK 签名验证通过。

构建、尺寸检查和模拟器结果见 [图标接入验收](../design/icon-acceptance/README.md)。桌面主题图标和最终遮罩由系统及 Launcher 决定，仍需目标手机确认。

## 安装与升级

- 下载 `PickMsg-v0.5.1-release.apk`；同时提供 `.apk.sha256` 校验文件。
- 与 v0.5.0 正式发布包使用相同签名，优先覆盖安装，不需要卸载旧版。
- 最低支持 Android 8.0。单色主题图标需要 Android 13 及以上，并由桌面决定是否启用。
- 本轮没有重新覆盖真机 ROM 和所有 Launcher；完整 Lint 的既有阻断项不属于本次图标更新的修复范围。
