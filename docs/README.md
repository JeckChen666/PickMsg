## 维护约定

- 当前功能以实现为依据，避免“全量”“随时恢复”等超出平台能力的承诺。
- 设计数值由设计规范与 `ui/theme/` 统一维护，首页只保留概述，不复制整套规格。
- 验证结论写清日期、设备、版本或构建来源；历史的 45 项测试结果不改写成后来的 50 项。
- 更新配图时检查页面名称、主题、字号和图片是否匹配；优先使用当前运行截图，不用概念图替代。
- 新增文档需有独立用途，并在本索引提供入口；不要把同一段状态说明复制到多份文件。
